# Overall Architecture

## Current State

The project is initialized as a macOS SwiftUI application generated by XcodeGen.

## Module Layout

| Directory | Responsibility |
| --- | --- |
| `MacPasteHistory/App` | App lifecycle, menu bar status item, standard window creation, and fullscreen-safe history overlay presentation. |
| `MacPasteHistory/Views` | SwiftUI views for the main panel and settings window. |
| `MacPasteHistory/Database` | SQLite initialization and database-specific errors. |
| `MacPasteHistory/Services` | Application support directory setup and future feature services. |
| `MacPasteHistory/Utils` | Shared defaults and logging. |
| `MacPasteHistory/Resources` | Info.plist and asset catalog resources. |
| `MacPasteHistoryTests` | Unit tests for foundational behavior. |

## Current Flow

1. `MacPasteHistoryApp` starts the SwiftUI app.
2. `AppDelegate` configures the accessory app mode and retained menu bar item.
3. The menu item or global shortcut opens history in a nonactivating top overlay that can join the current fullscreen Space.
4. Settings opens as a standard titled window; neither surface changes clipboard persistence behavior.
5. Startup creates the Application Support directories and opens `clipboard.db`.

## Notes

`HistoryPanelWindow` is intentionally separate from the settings window factory. This keeps the temporary, cross-Space history interaction from changing persistent settings-window behavior.
