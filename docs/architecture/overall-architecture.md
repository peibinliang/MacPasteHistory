# Overall Architecture

## Current State

The project is initialized as a macOS SwiftUI application generated by XcodeGen.

## Module Layout

| Directory | Responsibility |
| --- | --- |
| `MacPasteHistory/App` | App lifecycle, menu bar status item, and window creation. |
| `MacPasteHistory/Views` | SwiftUI views for the main panel and settings window. |
| `MacPasteHistory/Database` | SQLite initialization and database-specific errors. |
| `MacPasteHistory/Services` | Application support directory setup and future feature services. |
| `MacPasteHistory/Utils` | Shared defaults and logging. |
| `MacPasteHistory/Resources` | Info.plist and asset catalog resources. |
| `MacPasteHistoryTests` | Unit tests for foundational behavior. |

## Current Flow

1. `MacPasteHistoryApp` starts the SwiftUI app.
2. `AppDelegate` configures the accessory app mode and retained menu bar item.
3. Menu actions open the main history window, settings window, or quit the app.
4. Startup creates the Application Support directories and opens `clipboard.db`.

## Notes

The current implementation is the phase 1 foundation only. Clipboard monitoring, history persistence tables, settings persistence, privacy filtering, and shortcuts are intentionally left for later OpenSpec changes.
