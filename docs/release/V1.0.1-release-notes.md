# 粘易 V1.0.1

此版本已作为 GitHub 正式 Release 发布。当前应用仍使用本地 ad-hoc 签名，未经过 Developer ID 签名和 Apple 公证，首次下载或安装时 macOS 可能显示安全提示。

## 修复

- 修复长文本、多行文本和 cURL 内容可能无法写入复制历史的问题。
- 敏感内容过滤默认开启；用户确认风险后可以关闭，并记录 token-like 测试文本。

## 新增

- 设置中新增“版本信息与更新”页面。
- 支持自动定期检查更新、手动检查更新以及检查状态和错误提示。
- 集成 Sparkle 2.9.2，用于应用更新检查、验证、安装与重启。

## 安装

- 新安装：下载 `MacPasteHistory-1.0.1-2.dmg`，打开后将“粘易”拖入 Applications。
- 可使用同名 `.sha256` 文件核对下载的 DMG 完整性。

## 测试提示

- 请重点验证长文本、cURL、中文、URL、多段文本和 Emoji 的复制、搜索、打开及恢复。
- 请分别验证敏感过滤开启和关闭时的行为。
- 当前安装包未做 Developer ID 签名和 Apple 公证，macOS 可能显示安全提示；GitHub Release 的正式状态不改变这一签名边界。
