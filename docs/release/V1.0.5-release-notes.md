# 粘易 V1.0.5

V1.0.5 新增 AI 翻译，并调整 API Key 的默认本地存储方式，同时明确自动粘贴与 macOS 辅助功能权限的边界。

## 主要变化

- 新增 DeepSeek AI 翻译，支持简体中文、繁体中文、英语、日语和韩语；结果可编辑、可取消，并纳入 Token 用量统计。
- API Key 默认改存到应用的 Application Support 目录，不再在每次应用重启时访问钥匙串。
- 本地凭据采用仅当前用户可读写的 `0600` 权限与原子替换，并拒绝符号链接、目录、无效编码及异常大小的数据。
- 补充说明：恢复内容到剪贴板不需要辅助功能权限；向任意前台应用自动发送 `Command + V` 仍受 macOS 辅助功能授权保护。未授权时保留剪贴板并提示用户手动粘贴。

## 安全与兼容性说明

- API Key 文件是本地明文文件，不会上传；已存在的钥匙串项目不会自动迁移或删除。
- AI 润色和 AI 翻译仅在用户明确触发并确认远程处理后发送当前选中的文本。
- 产品负责人批准本版本继续使用 ad-hoc 签名，未配置 Developer ID Application，也未经过 Apple 公证。因此更新后 macOS 仍可能要求重新授予辅助功能权限。

## 安装与更新

- 新安装：下载 `MacPasteHistory-1.0.5-7.dmg`，打开后将“粘易”拖入 Applications。
- 已安装旧版本：可通过“关于与更新”检查 V1.0.5，或下载 DMG 覆盖安装。
- `MacPasteHistory-1.0.5-7.zip` 是 Sparkle 更新包；同名 `.sha256` 文件用于校验完整性。
