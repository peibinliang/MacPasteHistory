# 粘易 V1.0.2

此版本已作为 GitHub 正式 Release 发布，并支持从 V1.0.1 通过 Sparkle 检查更新。当前应用仍使用本地 ad-hoc 签名，未经过 Developer ID 签名和 Apple 公证，首次下载或安装时 macOS 可能显示安全提示。

## 新增

- 自动粘贴改为明确的可选配置，默认关闭；只有开启后才提示辅助功能权限，权限不足时自动退回仅复制模式。
- 新增 DeepSeek AI 文本润色，可配置模型，API Key 存储在 macOS 钥匙串中。
- 新增首次远程处理提示、可取消的润色预览、错误提示以及供应商返回的 Token 用量统计。

## 修复

- URL 类型记录的行内操作与“全部操作”使用相同筛选规则，不再混入通用文本操作。
- 普通文本仍保留 AI 润色入口，URL 等结构化内容只展示匹配类型的操作。
- 修改 AI 模型后无需按 Enter 即可保存。
- 从系统设置返回后会刷新辅助功能权限状态。
- 操作链返回上一步时会正确恢复 Token、提示、复制选项、标题和语法信息。
- 清空数据时，即使 Token 记录删除失败也会继续清理图片文件。

## 安装

- 新安装：下载 `MacPasteHistory-1.0.2-4.dmg`，打开后将“粘易”拖入 Applications。
- 已安装 V1.0.1：可在“关于与更新”中手动检查更新，或下载 DMG 覆盖安装。
- 可使用同名 `.sha256` 文件核对下载的 DMG 完整性。

## 测试提示

- 从 V1.0.1 的“关于与更新”页面执行手动检查，确认能发现 V1.0.2。
- 完成下载、替换和重启后，确认版本显示为 `1.0.2 (4)`，原有历史、收藏、设置和快捷键仍保留。
- 当前安装包未做 Developer ID 签名和 Apple 公证，macOS 可能显示安全提示；GitHub Release 的正式状态不改变这一签名边界。
