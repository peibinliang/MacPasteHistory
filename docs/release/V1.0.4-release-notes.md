# 粘易 V1.0.4

V1.0.4 是发布身份与更新工具链修正版本。本版本不会绕过或修改 macOS 辅助功能权限，而是补充跨版本代码身份检查，防止未来把不稳定签名误认为可保留系统授权。

## 主要变化

- 新增跨版本发布身份校验，检查 Bundle ID、Developer Team、Developer ID authority、designated requirement、Hardened Runtime 与公证状态。
- Release readiness 默认跟踪 V1.0.4 身份稳定 OpenSpec change。
- 正式更新 ZIP、校验器与 Sparkle appcast 生成支持从应用版本和构建号派生，不再锁定 V1.0.2。
- 正式候选包元数据缺失、顶层应用为符号链接或前置归档验证失败时，后续检查 fail-closed，不输出误导性通过结果。

## 已知限制

- 产品负责人批准 V1.0.4 暂时继续使用 ad-hoc 签名，未配置 Developer ID Application，也未经过 Apple 公证。
- ad-hoc 签名的代码身份随二进制 CDHash 改变，因此从旧版本更新到 V1.0.4 后，macOS 可能要求重新授予辅助功能权限；后续 ad-hoc 更新也可能重复出现。
- 新增的稳定身份门禁用于未来 Developer ID 发布，不代表本次 ad-hoc 制品已经获得稳定身份。

## 安装与更新

- 新安装：下载 `MacPasteHistory-1.0.4-6.dmg`，打开后将“粘易”拖入 Applications。
- 已安装旧版本：可通过“关于与更新”检查 V1.0.4，或下载 DMG 覆盖安装。
- `MacPasteHistory-1.0.4-6.zip` 是 Sparkle 更新包；同名 `.sha256` 文件用于校验完整性。

## 版本

- 构建号：`6`
