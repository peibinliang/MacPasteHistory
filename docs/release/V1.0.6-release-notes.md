# 粘易 V1.0.6

V1.0.6 为稳定性与性能优化热修复版本，重点解决长期常驻运行下的偶发闪退、超长文本主线程卡死及图片预览内存暴涨问题。

## 主要变化

- 修复搜索框快速编辑或清空时移除结构化搜索词元（`type:`、`app:` 等）触发 `String.Index` 越界导致的闪退。
- 修复 `ContentClassifier` 与 `SensitiveContentDetector` 在处理 `200 KB+` 超长单行文本时的灾难性正则回溯，消除长达数十秒的主线程卡死与 CPU 飙升。
- 将剪贴板图片编解码、缩略图生成、内容 Hash、敏感内容检测、内容分类与 SQLite 写入迁移至串行后台队列，并增加每 `50` 次捕获或每 `30` 分钟自动执行的运行期定期清理，避免长期不退出运行导致历史数据无限膨胀。
- 新增基于 `ImageIO` 的按尺寸下采样预览缓存（`PreviewImageCache`）与只读 SQLite 异步列表加载，复用单实例历史浮窗并将时间线列表改为惰性渲染（`LazyVStack`），修复多时间分组提前触发分页及大图全量解码引发的 `1 GB+` 内存暴涨。
- 修复沙箱环境下切换界面语言点击“立即重启”后未能拉起新实例、模态确认框弹出时历史浮窗被提前收起，以及空态“打开设置”按钮无响应的问题。

## 安全与兼容性说明

- 完全兼容 V1.0.5 及更早版本的本地 SQLite 历史数据库、图片目录与用户偏好设置，无需数据库迁移。
- 剪贴板历史、图片与缩略图继续仅保存在本机沙箱目录；AI 润色与翻译仍仅在用户明确触发并确认后发送当前选中文本。
- 本版本继续使用 ad-hoc 签名，未配置 Developer ID Application，也未经过 Apple 公证；开启“直接粘贴”的用户在覆盖更新后如遇系统提示，需在“系统设置 → 隐私与安全性 → 辅助功能”中重新勾选一次“粘易”（仅复制恢复到剪贴板不需要辅助功能权限）。

## 安装与更新

- 新安装：下载 `MacPasteHistory-1.0.6-8.dmg`，打开后将“粘易”拖入 Applications。
- 已安装旧版本：可通过“关于与更新”检查 V1.0.6，或下载 DMG 覆盖安装。
- `MacPasteHistory-1.0.6-8.zip` 是 Sparkle 更新包；同名 `.sha256` 文件用于校验完整性。
