# 粘易 V1.0.3

V1.0.3 是核心稳定版本，重点改善捕获一致性、敏感内容识别、图片存储对账、搜索生命周期、粘贴流程和 SQLite 并发证据，不包含 V1.1 的 Slots、Tags 或 FTS5 新功能。

## 主要变化

- 单次观察到的剪贴板事件使用同一份来源应用与捕获时间快照，避免管线内来源漂移。
- Sensitive Detector V2 使用结构化类别、置信度和不含原文的原因码，并校验 Luhn 卡号、身份日期/校验位及带上下文的凭据。
- 启动清理后异步扫描图片存储；普通孤立、缺失、损坏或归属不确定文件保持不动，只重建安全缩略图并删除超过 24 小时且未引用的 `mph-image-*.tmp`。
- 历史与内容操作结果统一通过 `PasteCoordinator` 处理剪贴板写入、权限、目标应用、命令派发、取消、fallback 和精确一次记账。
- 搜索 Task 具有明确取消和结果所有权；关闭/替换历史面板或刷新列表不会被旧搜索结果覆盖。
- SQLite 继续使用 DELETE journal、1,000 ms busy timeout 和 `BEGIN IMMEDIATE`；WAL 实验未通过 sidecar 生命周期门禁。
- 新写入时间保留亚秒精度，同时继续读取 V1.0.2 的秒级时间字符串。
- AI 润色成功写入 provider token usage 或清空全部数据后，已打开的设置页会立即刷新；provider 返回模型别名时仍计入发起请求的当前配置模型。

## 已知边界

- 来源应用是 0.5 秒轮询观察时的前台应用；如果复制后在下一次轮询前切换应用，macOS pasteboard 不提供真实复制来源。Blocked Apps 是 best-effort 隐私控制，不是绝对安全边界（PD-005）。
- 已加入由不可变 `V1.0.2` 标签构建的 build 4 应用实际创建并脱敏的 SQLite fixture；checksum、完整性、外键、journal、迁移、capture event 与 AI usage 升级验证均通过（PD-006 已解决）。
- 当前发布环境没有 Developer ID Application 身份，DMG 与 Sparkle ZIP 使用 ad-hoc 签名，未经过 Apple 公证；首次下载或安装时 macOS 可能显示安全提示。GitHub Release 的正式状态不改变这一签名边界。
- V1.0.3 的隔离 Release GUI 已覆盖捕获、搜索、恢复、Blocked Apps、Automatic Paste fallback、内容动作、设置、清空数据和重启；`SystemUIServer` 菜单栏状态项与真实全局快捷键因自动化能力限制由产品负责人批准本版本豁免（PD-007），后续版本仍需补回人工 smoke。

## 安装与更新

- 新安装：下载 `MacPasteHistory-1.0.3-5.dmg`，打开后将“粘易”拖入 Applications。
- 已安装旧版本：可通过“关于与更新”检查 V1.0.3，或下载 DMG 覆盖安装。
- `MacPasteHistory-1.0.3-5.zip` 是 Sparkle 更新包；同名 `.sha256` 文件用于核对字节完整性。
